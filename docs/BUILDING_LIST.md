# VandyMap — In-Scope Building List

**Reviewed and confirmed 2026-09-06.** This is the authoritative set of buildings for Phase 1 data entry. Anything not here lives in [BUILDING_LIST_DEFERRED.md](BUILDING_LIST_DEFERRED.md), which is the pool to pull from for future additions.

Building numbers come from Vanderbilt Facilities Information Services' [Building Directory](https://cpc-fis.vanderbilt.edu/map/campusviewer/infopages/BuildingDirectory.html) and are kept as a stable key for data entry. Entries without a number were added during review and aren't in that directory under those names.

Checkboxes now track **data-entry progress** — check one off when its TOML file exists and is filled in.
